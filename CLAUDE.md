# CLAUDE.md

## Design Context

This project has `PRODUCT.md` (register, users, purpose, brand personality, anti-references) and `DESIGN.md` (color tokens, typography, elevation, components, do's/don'ts) at the project root, plus `WORK_ORDER.md` for the full phase-by-phase build spec. Read these before making any UI change — they carry the Marquee-dialect design system's non-negotiable rules (no gradients/glass/glow, semantic color as points not fills, tabular numerics, big-figure rate notation).

`.impeccable/live/config.json` is configured for `/impeccable live` (in-browser variant iteration) against `src/app/layout.tsx`.
